# N2-Daily-App 本地长期指令文件

将以下两个文件放到 `N2-Daily-App` 项目根目录：

- `WORK_INSTRUCTIONS.md`：给 Work 使用。课程生成、Week/Day 连续性、12 月 6 日考试倒排、Week 03 恢复更新规则。
- `AGENTS.md`：给 Codex 使用。程序、资料源下载/标准化、许可、schema、验证、PWA、GitHub 与自动发布。

建议以后：
- Work：只需说“读取 WORK_INSTRUCTIONS.md，按本地规则继续更新课程。”
- Codex：只需说“读取 AGENTS.md，按本地规则继续。”
