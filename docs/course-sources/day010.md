## ③ 今日N2语法｜20分钟

### ～一方（いっぽう）で

**中文意义：**一方面……另一方面……

**使用说明：**用于呈现同一事物的两个不同侧面。阅读题里看到「一方で」要高度敏感，因为作者往往正在从前面的优点切换到限制、问题或另一种观点。

> オンライン授業（じゅぎょう）は時間（じかん）を有効（ゆうこう）に使（つか）える一方（いっぽう）で、学生同士（がくせいどうし）の交流（こうりゅう）が減（へ）るという問題（もんだい）もあります。

在线课程一方面可以有效利用时间，另一方面也存在学生之间交流减少的问题。

### ～ことによって

**中文意义：**通过……；由于……而……

**使用说明：**既能表示**手段／方法**，也能表示**原因**。阅读时不要机械翻译，要判断：

**怎么实现的？ → 手段**  
**为什么发生？ → 原因**
