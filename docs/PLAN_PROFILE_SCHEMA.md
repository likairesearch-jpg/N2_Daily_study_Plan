# Plan Profile interface (v1)

Local files: config/profiles/<id>.json. Machine contract: schemas/plan-profile.schema.json; validated by tools/plan.cjs. No profile edit changes historical courses or triggers generation/publishing.

Required: schemaVersion=1, id (lowercase slug), name, mode official/experiment, targetJlptLevel N5..N1, vocabularyPerDay (1..100), grammarPerDay/readingQuestionsPerDay/listeningQuestionsPerDay (1..30), vocabularyWeight/grammarWeight/readingWeight/listeningWeight/reviewPriority (low/normal/high), readingStyle/listeningStyle (jlpt-n5..jlpt-n1), createdAt/updatedAt. Optional extensions: kanjiEmphasis, speakingEmphasis, reviewRatio, mockFrequencyDays, maxDailyMinutes, reviewWeights d1/d3/d7.

Official Default was initialized once from unchanged Week03: 12 words, 3 grammar, 2 reading questions, 1 listening question. This is a daily target; review-day treatment remains explicit. Official profiles cannot be deleted or converted to experiment in place. Save As creates a new experiment profile. Save changes only future generation. config/active-profile.json records the selected profile. UI reads/writes real files and preserves extension fields.

Context generation uses explicit selected profile or persisted active profile, and embeds profileId/profileName/profileMode/profilePath/profileSchemaVersion/profileHash plus full parameters snapshot. Hash is SHA-256 of the canonical parameter snapshot; later file edits do not mutate earlier bindings. Future Week04+ must copy this object as profileBinding with official mode. Experiment envelope requires experiment binding. Profile counts/weights override generic workload defaults, never honesty, review rules, provenance or validator requirements.

Experiment contract: {schemaVersion:1,id:experiment-slug,title,profileBinding,sessions:[...]} in data/drafts/experiments/. Sessions use the Day learning fields but omit week/day; IDs are session-local, namespaced by the client. Every experiment vocabulary entry requires examples[] of Japanese text objects. Validate/promote writes only data/experiments/ and its hash approval; experiments never enter formal coverage or Day history. Empty new draft scaffolds are intentionally invalid until Work writes sessions. No teaching content is generated by Plan Lab.

Client dictionary is generated solely from words occurring in formal/experiment text, plus grammar/vocab actually taught. English reference meanings remain labeled English; Chinese only comes from existing course data. Source/license metadata is preserved. Original Week01-03 collocations are retained as originally supplied; the application never invents complete example sentences for historical courses. Future/experiment items require explicit examples.

N2 coverage report: reports/n2-coverage.json. Primary totals use any upstream N2 assignment; exact resolved counts and conflicts are separate. Coverage is stable-ID/conservative matching, not mastery; kanji instructional coverage is unknown. Forecasts assume every remaining pre-exam day teaches new distinct N2 candidates, without rest/review deductions.

The context also includes a ready-to-copy profileBinding object. Work copies that object into a new official Week or experiment envelope, not the whole context pack.
